# 2026-09-08

## 修复：批量 AI 生成期间删除视频会被“复活”
- 根因：`VideoList.vue` 的 `handleAiBatchGenerateTitle` 用 `let pendingVideos = [...props.videos]` 初始快照，`onApplied` 每完成一个任务就把整份快照 emit 回去；批量期间删除的视频仍在快照里，后续任务完成时被写回列表。
- 修复：
  1. `onApplied` 改为「最新 `props.videos` + 本地 `appliedTitles` Map 合并」后 emit：标题累积在 map 保证并发不互相覆盖，列表始终以最新 props 为基准保证删除不复活。
  2. `runAiTitleForVideo` 增加防线：图像识别完成后、应用标题前各检查一次 `props.videos.some(id)`，不存在则 `return { status: 'skipped' }`（不再 set aiInfos、不再回填标题）。
  3. 批量 worker 取任务时先跳过已删除的视频（不再发起 AI 请求）。
- 该防线同时覆盖单条生成、清空列表等场景。`npx vue-tsc --noEmit` 通过。
