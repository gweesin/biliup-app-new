# 2026-09-10

## VideoList.vue：视频原文件路径点击复制
- `VideoList.vue` 的 `.video-file-path`（标题下方的浅色小字）增加点击复制功能：
  - 移入时 `cursor: pointer` + hover 高亮（蓝色文字 + 浅蓝背景）。
  - 点击调用新增的 `copyVideoPath(video)`：用 `navigator.clipboard.writeText` 复制 `getVideoLocalPath(video)`（original_file_path 优先），成功/失败均有 toast 提示（`utilsStore.showMessage`）。
  - 展示样式改为 flex 布局，加了 `CopyDocument` 复制图标与省略文本 span（`.video-file-path-text`）。
- 复制方案沿用 `LoginView.vue` 已有的 `navigator.clipboard.writeText` 先例，未新增 Tauri 剪贴板插件。
