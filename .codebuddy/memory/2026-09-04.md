# 2026-09-04

## 优化：上传队列接口不再下发 base64 头像
- 问题：`get_upload_queue` 每条任务都带 `user.avatar`（base64 图片），2 秒轮询一次导致 IPC 传输数据量大。
- 后端改动：`src-tauri/src/services/upload_service.rs` 的 `get_upload_queue` 中，克隆任务后 `cloned.user.avatar.clear()` 再返回（仅影响下发的副本，队列中原始任务不受影响）。
- 前端改动：`src/stores/upload.ts` 新增 `fillUserAvatar(queue)`，在 `getUploadQueue` 拿到队列后按 `task.user.uid` 从 `authStore.loginUsers` 补全头像，UI（`UploadQueue.vue` 的 `task.user.avatar`）无需改动。
- 校验：`npx vue-tsc --noEmit` 通过，`cargo check` 通过。
- 注意：前端若要取任务头像，必须走 uploadStore（已补全），不要直接依赖后端返回的 `user.avatar`。
