# 2026-09-12

## 修复：打包后 AI 生成标题执行 ffmpeg 会闪命令行窗口
- 现象：打包后的应用是 Windows GUI 子系统（无控制台），`src-tauri/src/utils/ffmpeg.rs` 里用 `tokio::process::Command` spawn ffmpeg/ffprobe 时，系统给子进程分配新控制台，执行时闪现 cmd 窗口。
- 修复：`run_process` 与 `run_process_with_stdin` 两处在 spawn 前加 `#[cfg(windows)] cmd.creation_flags(0x0800_0000);`（CREATE_NO_WINDOW）。
- tokio 1.53.1 API 坑（已从源码确认）：`tokio::process::Command::creation_flags` 是 `Command` 的**固有方法**（cfg_windows! 内定义，无需 import trait）；`tokio::process::CommandExt` trait 已是 private（E0603 不可 use）；`tokio::process::Child::from_std` 已移除（E0599）。不要再用旧写法。
- 影响范围：AI 截帧（capture_frame_near_end / probe_video_duration 等所有 ffmpeg/ffprobe 调用）均受益。
