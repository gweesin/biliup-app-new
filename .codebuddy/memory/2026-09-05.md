# 2026-09-05 工作日志

## AI 标题生成功能（新增，2026-09-05）
- 需求：在 `VideoList.vue` 标题末尾加 codicon sparkle 图标，点击截取视频"倒数第三秒"画面提交 AI（OpenAI 兼容视觉接口），按指定 prompt 生成 6-10 个候选标题，点击应用。
- 方案确认：OpenAI 兼容接口（自填 BaseURL/Key/模型）+ 优先本机 ffmpeg 截帧 + 全局设置页新增 AI 配置。
- Rust 端：
  - `models/user_config.rs`：新增 `AiConfig { enabled, base_url, api_key, model, ffmpeg_path }`（默认 base_url=https://api.openai.com/v1），`ConfigRoot` 新增 `ai` 字段，`save_global_config` 增加 `ai` 参数。
  - `commands/ai.rs`（新建）：命令 `generate_ai_titles(app, video_path) -> Vec<String>`。流程：校验 AI 配置 → `resolve_ffmpeg`（配置路径→PATH→Windows 常见目录/scoop/winget）→ ffprobe/ffmpeg 探测时长 → `ffmpeg -ss (dur-3) -frames:v 1 -c:v mjpeg pipe:1` 截帧 base64 → POST `{base}/chat/completions`（多模态 content: text+image_url，Bearer 鉴权，120s 超时）→ 解析 content → 清洗行/JSON 数组 → 去重最多 12 条。未配置/未装 ffmpeg 返回中文错误。
  - `commands/mod.rs` 增加 `pub mod ai`；`lib.rs` invoke_handler 注册 `generate_ai_titles`。
- 前端：
  - `stores/user_config.ts`：导出 `AiConfig` 接口与 `createDefaultAiConfig()`，ConfigRoot 增加 `ai`，`updateGlobalConfig` 传 `ai` 对象。
  - `stores/utils.ts`：新增 `generateAiTitles(videoPath)` 封装 invoke。
  - `GlobalConfig.vue`：新增 "AI 设置" 分区（开启开关、Base URL、API Key、模型名、ffmpeg 路径+选择文件按钮）。
  - `VideoList.vue`：`.video-title` 末尾加 sparkle svg（紫色 hover 发光）；点击 → 校验本地 path 与 AI 配置 → 弹窗加载候选 → 点击候选回填 title（`emit('update:videos')`）。
- 校验：`cargo check` 通过；`npx vue-tsc --noEmit` 通过。
- 遗留：AI 调用链路需要真实 API Key/ffmpeg 才能端到端实测，尚未实机验证。
